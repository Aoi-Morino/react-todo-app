# マイオリジナルTodoApp

**公開ページ：** [GitHub Pages](https://aoi-morino.github.io/react-todo-app/)

## 概要

TypeScriptおよびReactの学習を目的として制作した「Todoアプリ」です。

ブラウザ上で動作し、ローカルストレージを利用してデータを永続化しています。

## 主な機能

- タスクの追加
  - 32文字以内で自由に名前を付けられる
  - 3段階の優先度を選択可能
  - 期限を自由に設定可能
- タスクごとの色分け
  - ユニバーサルデザインを意識した配色
- ゴミ箱機能
  - 削除したタスクを一度ゴミ箱に移動

## 使用技術

- 言語：**TypeScript**
- ライブラリ：**React**
- CSSフレームワーク：**Tailwind CSS**
